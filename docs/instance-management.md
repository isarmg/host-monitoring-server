# 新建实例与配对

管理 Web 只保留「新建实例」入口，不再提供独立的「邀请与配对管理」或「激活配对」入口。

1. 点击「新建实例」，输入实例名称（最多 32 个 Unicode 字符）；创建成功后窗口立即关闭，长期授权码出现在实例列表中，可直接复制。
2. 授权码不设有效期，由服务端加密保存，可在实例列表中查看或更换；不要放入 URL 或日志。
3. 在主机启动 Client 配对，打开 Client 给出的链接，登录后核对设备信息并输入配对码。
4. Client 确认后开始上报；授权码不会因本次配对而被消耗。
5. 更换授权码会立即撤销该实例当前客户端凭据并将实例恢复为待配对状态，Client 必须使用新码显式重新配对。未使用的实例也可取消，取消后授权码不可再用。

授权码没有到期字段或定时失效逻辑。设备发起的短期配对请求仍有 15 分钟会话期限以限制未认证请求占用；请求超时不取消授权码，Client 可重新发起请求。此期限不是授权码有效期。

取消与绑定在数据库事务中互斥，已绑定实例通过更换授权码撤销旧凭据并重新配对。管理员认证、CSRF、设备确认和审计继续保留。

本次数据结构为 Host Monitoring 0.9.20 / Schema 6。不为旧库保留兼容字段或自动转换；运行中的旧库没有被清空或迁移，升级和恢复仍由 sarmg-upgrade 负责。
