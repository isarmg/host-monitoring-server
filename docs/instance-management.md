# 新建实例与配对

管理 Web 通过「新建实例」创建待配对实例；设备激活由 Client 提供的确认链接进入。

1. 点击「新建实例」后立即以默认名称创建；名称可在详情中修改，允许 1–32 个 Unicode 字符。首尾按 Unicode White_Space 裁剪，控制字符会被拒绝。
2. 授权码不设有效期，由服务端加密保存，可在实例列表中查看或更换；不要放入 URL 或日志。
3. 在主机启动 Client 配对，打开 Client 给出的链接，登录后核对设备信息并输入配对码。
4. Client 确认后开始上报；授权码不会因本次配对而被消耗。
5. 更换授权码会立即撤销该实例当前客户端凭据并将实例恢复为待配对状态，Client 必须使用新码显式重新配对。未使用的实例也可取消，取消后授权码不可再用。

授权码没有到期字段或定时失效逻辑。设备发起的短期配对请求仍有 15 分钟会话期限以限制未认证请求占用；请求超时不取消授权码，Client 可重新发起请求。此期限不是授权码有效期。

取消与绑定在数据库事务中互斥，已绑定实例通过更换授权码撤销旧凭据并重新配对。管理员认证、CSRF、设备确认和审计继续保留。

## Web 上报日志

实例的「日志」页默认选择服务器当天，并可用日期选择器查看其他服务器日期。服务端按每份报告的接收时间归属日期，返回所选日全部记录，不分页；每条记录同时显示服务器时区下的接收时间、客户端采集时间和报告 ID。客户端补传或时钟偏差不会改变报告所属的服务器日期。单次 Web 请求使用 Foundation 当前支持的 64 MiB 响应预算和 120 秒超时，超出预算的日期会显示读取错误。已按保留策略清除的报告不再出现在该页。

当前数据库格式为 Host Monitoring `0.9.26` / Schema `7`，应用发行版本为 `0.9.31`。
启动严格校验当前数据库身份，不自动转换或修复。产品和 `sarmg-upgrade` 当前没有受支持的 Host
升级、备份或恢复流程，详见[运维边界](operations.md#9-数据库身份与当前不支持的数据操作)。
