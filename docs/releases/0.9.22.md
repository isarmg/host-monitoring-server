# Host Monitoring Server 0.9.22

- “新建实例”现在直接使用默认名称创建，不再打开名称输入弹窗；登录后统一进入实例列表。
- 配对管理统一显示账户名、不可变内部账户 ID 和可更换密码；新建及更换密码均使用 32 位小写英文字母或数字，Client 仍只凭授权码配对。
- 实例与 Host 摘要接口移除分页参数、计数和分页响应字段，改为按账户名忽略大小写稳定排序并一次返回全部实例。
- 升级至 Foundation 0.8.8，沿用 5 秒自动消失通知和结构化表格左对齐合同。
- 同步 CI 的工作区协议版本断言，使其验证 0.9.22 的 Server 与 protocol 边界。
