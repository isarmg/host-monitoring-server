# Host Monitoring Server 0.9.18

- 配对事务不存在时返回专用的 `pairing_transaction_not_found` 错误码和 request ID，不再使用通用 `not_found`。
- 到期配对事务持久转为 `expired` 并保留 24 小时，期间状态接口返回明确的 Expired；保留期后才限量清理。
- 错误响应不包含授权码、token hash 或 polling secret；错误正文继续使用严格 Foundation envelope。
- 仅接受 0.9.18 当前配置、协议、Schema identity 和发行目录，不提供旧版本兼容或进程内迁移。
