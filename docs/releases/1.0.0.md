# xsos 1.0.0

[发行页](https://github.com/isarmg/xsos/releases/tag/v1.0.0)提供 Linux x86_64 GNU 归档与同名 `.sha256`。包内包含服务二进制、内嵌管理 Web 的资源清单、systemd unit 和部署说明。

## 本版功能

主机配对、CPU/内存/磁盘/网络及可用硬件数据、完整最新详情、历史趋势和原始上报日志。报告 schema 1，数据库结构 revision 1。

## 部署与验证

从[安装手册](../server-release-readme.md)开始。实际源码身份由归档的 manifest 和 binary identity 给出；main 的后续提交不自动改变已发布资产。

构建与测试分层见[开发指南](../development.md)，产品范围见[功能说明](../feature-inventory-and-tradeoffs.md)。浏览器或协议夹具验证覆盖对应软件行为，真实设备、驱动与采集表现需在目标主机验证。
