# host-monitoring-server 0.9.31

- 实例「日志」页以服务器本地日期筛选已保存的上报记录，默认当天，并一次显示所选日期的全部记录。日期归属使用服务器接收时间；每条记录显示接收时间、客户端采集时间、UTC 偏移和报告 ID。
- 日志日期按相邻的服务器本地午夜划分，夏令时切换日使用该日实际长度。单次 Web 响应预算为 64 MiB、120 秒；超过预算会显示读取错误。原始报告仍按当前保留策略清理。
- 历史趋势在缺失采样区间保留断点，并显示孤立有效采样；详情页说明客户端采集时间与服务器接收时间的差异。
- 实例名称编辑在列表刷新和重新绑定时保留尚未提交的输入；在线状态使用客户端声明的采样节奏估算。
- 报告协议仍为 schema 3；数据库结构身份仍为 0.9.26 / Schema 7。
- 管理员服务与 Web 共享组件固定到 Foundation Server 0.9.2。

## 验证

Rust 测试、严格 Clippy、Web 生产构建以及 Chromium、Firefox 浏览器验收通过。日志验收覆盖大量同日记录和夏令时边界。
