# Host Monitoring Server 0.9.13

This release repairs the Host Client pairing and recovery contract. Client release strings are now diagnostics only; explicit pairing protocol version 1 controls compatibility, so clients such as 0.9.15 and 0.9.999 are accepted when they speak the supported protocol.

Clients can verify an existing bearer credential through the bounded, no-store `GET /api/v2/host-monitor/credential-status` endpoint. Pairing also supports the explicit `recover_identity` mode. Recovery can bind a newly issued authorization code to the Client's previous Host UUID only when that UUID is absent, and it never overwrites an existing host or device invite.

The SQLite contract advances to schema revision 6. This project intentionally has no in-process upgrade path; deploy a new empty database or use a separately verified upgrade tool. The administrator Web retains the unified instance-list navigation and deletion behavior completed for this release.
