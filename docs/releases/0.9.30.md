# host-monitoring-server 0.9.30

- 管理台将 IP、MAC、链路属性与流量计数按唯一接口名合并在“网络接口”中。接口属性不再冒充“网络硬件”；后者只显示新版 Client 独立确认的物理网卡。
- 核对了显卡、温度传感器、磁盘和其他实例列表的采集及展示路径。显卡沿用 0.9.29 的保守合并规则；物理磁盘 SMART 健康与挂载卷按各自含义展示。
- 报告硬件快照新增可选的 `physical_networks` 字段；旧版 Client 报告仍可读取。主机级指标汇总和数据库结构不变。数据库结构身份仍为 `0.9.26` / Schema `7`。

## 验证

- Web 生产构建与 Chromium、Firefox 浏览器验收通过；逻辑接口合并和物理网卡独立展示的回归检查通过。
