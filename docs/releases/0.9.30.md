# host-monitoring-server 0.9.30

- 同一网卡此前在“网络硬件”和“网络接口”中各显示一张卡片。管理台现在按唯一接口名合并 IP、MAC、链路状态与流量计数；无法唯一匹配的网络硬件仍单独显示。
- 核对了显卡、温度传感器、磁盘和其他实例列表的采集及展示路径。显卡沿用 0.9.29 的保守合并规则；物理磁盘 SMART 健康与挂载卷按各自含义展示。
- 原始报告、主机级指标汇总和数据库结构不变。数据库结构身份仍为 `0.9.26` / Schema `7`。

## 验证

- Web 生产构建与 Chromium、Firefox 浏览器验收通过；网卡合并及无法匹配时保留记录的回归检查通过。
