# Host Monitoring Server 0.9.26

- 新增硬件报告字段与严格校验：CPU 型号和频率、网卡硬件信息、风扇/电压/电流/功率/能量，以及 SMART / NVMe 健康数据。
- 原始数据、小时聚合、历史 API 和网页新增 CPU 频率、GPU 功耗/频率、最高风扇转速、磁盘温度和 NVMe 寿命消耗指标。
- 接收 Client 0.9.31 的 Windows ADLX / IGCL 只读遥测，展示显卡温度、功耗、时钟、风扇和电压。具体传感器取决于硬件与驱动。
- 保持硬件监控定位：无进程管理、远程命令下发或硬件控制接口。

## 当前版本要求

本版仅接受报告 schema **2**；请同步使用 **Client 0.9.31**。数据库身份为 `host-monitoring` / `0.9.26` / schema revision **7**。服务端不提供旧协议兼容、旧库迁移或自动转换；旧库不能直接用于本版。本次发布不会修改任何已部署实例或数据。

## 验证与产物

Rust 工作区测试、严格 Clippy、前端构建及 Chromium/Firefox 页面验收通过。正式归档由标签工作流从固定源码构建，包含部署说明、完整性清单和 SHA-256 校验文件。仅提供 x86_64 GNU/Linux Server 归档。
