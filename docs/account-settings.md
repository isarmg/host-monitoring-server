# 修改当前账号

登录管理 Web 后，点击上方菜单栏最右侧的圆形人物图标，输入账号名称和当前密码。需要修改密码时填写并确认新密码；留空则保留原密码。点击“保存账号”后，使用新账号信息重新登录，其他浏览器的旧会话也会失效。

账号名称是登录用户名，不会改变内部账号 ID 或 Host Monitoring 业务数据归属。此入口只修改当前登录
账号；系统仅允许一个管理员，不提供创建管理员或角色管理入口。

会话保持修复：并发请求按不同顺序更新活跃时间时不会再误判退出。正常空闲到期和显式注销仍需重新登录。

账号改名不改变稳定的内部账号 ID。Server 只接受当前 `0.9.22` Schema；账号设置不是数据库升级或迁移
入口，也不会让非当前数据库变为可读。
