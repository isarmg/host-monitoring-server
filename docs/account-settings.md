# 修改当前账号

使用正式 xcss 的共用账号页。点击菜单栏右侧的人物图标进入普通账号设置页，路由为 `#account`；它与实例列表、详细信息和日志页面共用工作区。人物图标保持原来的形状、颜色和尺寸，不增加选中标记或下划线。

内容块依次提供用户名（默认当前用户名）、当前密码、新密码、确认新密码和保存按钮。新密码留空则保留现有密码；填写时必须满足 xcss 的密码规则，并与确认内容一致。离开页面或刷新时清空未保存的密码。

点击保存后，通过 xcss 原有账号更新接口验证当前密码并原子更新账号；验证失败时不产生修改。成功后原有登录会话失效，需要使用新的账号信息重新登录。页面显示面向用户的错误提示，不显示请求标识。账号设置不使用弹窗或分步验证，不增加独立的密码验证接口。

登录页保留灰色内容块、浅色下黑色文字、红色错误提示和深浅色切换。首次访问跟随系统主题，手动选择在刷新、登录和退出后保留；存储不可用时保留当前页面的选择。右上角的语言和主题图标使用管理页相同的 `1em` 尺寸，统一主题存储键为 `sarmg:theme`。

账号名称是登录用户名，不会改变内部账号 ID 或 xsos 业务数据归属。此入口只修改当前登录
账号；系统仅允许一个管理员，不提供创建管理员或角色管理入口。

并发请求按实际活跃时间维护会话；正常空闲到期和显式注销后需要重新登录。

账号改名不改变稳定的内部账号 ID。Server 只接受当前 `1.0.0` Schema。账号设置只修改当前管理员资料。
