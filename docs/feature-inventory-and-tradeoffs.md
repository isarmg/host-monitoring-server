# xsos 功能范围

## 可以完成的工作

| 工作 | 使用入口 | 数据含义 |
|---|---|---|
| 监控 CPU、内存、磁盘、网络与硬件 | [使用指南](usage.md) | 最新完整报告与平台可用读数 |
| 查看历史趋势 | [硬件数据](hardware-monitoring.md) | 原始标量和小时聚合，缺失保持空值 |
| 浏览原始上报日志 | [实例管理](instance-management.md) | 按服务器接收日期，每页最多 50 条 |
| 新增、配对和维护主机 | [实例管理](instance-management.md) | 长期授权码与独立设备凭据 |
| 维护账号、服务和保留期 | [运维](administration.md) | 私有单实例 SQLite 状态 |

## 设计选择

- 单机 SQLite 与单 writer 让部署简单，并通过有界队列约束写竞争。
- Client 先保存本地 spool，应对短期断网；默认 64 MiB，持续离线需处理容量压力。
- 原始报告与小时聚合分层保存，平衡详细查询和长期容量。
- 桌面客户端提供原生安装包和平台采集器；macOS 有 GPU 清单，实时读数按系统可用性表示。
- 移动端提供宿主驱动 Rust 库，调度、权限、网络、凭据存储由宿主负责，未发布 APK/IPA。

产品聚焦只读主机监控。远程管理、告警规则、审计查询/导出和多活数据库不属于当前功能。已有审计及会话等控制面表仍需计入长期容量；其保留策略不同于遥测。
